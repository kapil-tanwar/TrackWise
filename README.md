## TrackWise — Personal Finance Visualizer

TrackWise helps you track income and expenses, visualize spending with rich charts. Built with Next.js App Router, NextAuth, MongoDB/Mongoose, Tailwind, and Radix UI.


### Installation (Local)

1) Clone and install
```bash
git clone <url>
cd fileName
npm install
```

2) Configure environment
Create a `.env` in the project root:
```bash
MONGODB_URI="......",
NEXTAUTH_SECRET="....."
NEXTAUTH_URL="http://localhost:3000"
```

4) Run
```bash
npm run dev
```
